爆款选题挖掘器

输入领域/受众 → 自动生成爆款选题清单+标题公式+发布时间建议+热度潜力评分。自媒体/内容创作者选题必备。支持 Agent JSON 接口。

实用场景：自媒体运营者每天想"今天写什么选题"——选题枯竭、标题不吸引人、不知道几点发。本工具按领域+受众生成爆款选题清单（含标题公式、发布时间、热度潜力评分），直接进选题库。

实用场景与实例

场景：自媒体/短视频创作者选题；公众号小编；内容运营。痛点：选题枯竭、标题弱、不知道几点发。用法：输入领域+受众 → 生成爆款选题（标题+公式+时间+热度分）。
实例：输入"健身/上班族"，生成："久坐上班族10分钟肩颈放松"（热度高，建议12:00发）、"减脂期怎么吃不怕胖"（热度中，建议18:00发）等，含标题公式与热度潜力评分。
Agent 用法：访问 ?tool=content-idea-miner&input={"niche":"健身","audience":"上班族","count":6}&format=json 返回 JSON（选题数组），Agent 可直接读入选题库。
