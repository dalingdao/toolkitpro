## 特点

- ✅ **纯前端** — 无后端，无服务器，数据不出浏览器
- ✅ **即开即用** — 无需注册，无需安装
- ✅ **响应式** — 支持桌面和移动设备
- ✅ **开源** — HTML5 + Vanilla JS，无依赖框架

## 技术栈

- HTML5 + CSS3 + Vanilla JavaScript
- 无构建工具，无 npm 依赖（除 QR Master 使用 qrcode-generator CDN）
- 每个工具都是独立的单文件 HTML
