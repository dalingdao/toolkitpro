多语言一致性检查器

对比多语言文案文件 → 检测缺失键/多余键/占位符不一致/长度异常 → 一致性报告。i18n 国际化文案同步检查必备。支持 Agent JSON 接口。

实用场景：前端团队做多语言（i18n），改了 en.json 加了个键但忘了改 zh.json——界面出现未翻译、占位符 {name} 漏了、文案超长。本工具一键对比多语言文件，报出缺失键/多余键/占位符不一致/长度异常，上线前质检。

输入多语言文件（JSON，格式：{"en":{...},"zh":{...}}）

示例

实用场景与实例

场景：前端多语言发布前检查；本地化团队同步翻译。痛点：键不同步、占位符漏翻、文案超长。用法：粘贴多语言 JSON → 检查缺失/多余/占位符/长度 → 一致性报告。
实例：输入 {"en":{"greet":"Hello {name}","save":"Save"},"zh":{"greet":"你好{name}"}}：报告 zh 缺 "save" 键、greet 占位符一致（{name}）、无多余。提示补翻译 save。
Agent 用法：访问 ?tool=i18n-checker&input={"locales":{"en":{"greet":"Hello {name}"},"zh":{"greet":"你好{name}"}}}&format=json 返回 JSON（缺失/多余/占位符/长度报告），Agent 可直接读入质检。
