What are HTML Entities?

HTML entities are special codes that represent characters in HTML. They start with & and end with ;. For example, &lt; represents the less-than symbol < and &amp; represents the ampersand &.

Why Encode HTML?

  • Prevent XSS: Encoding user input before rendering prevents cross-site scripting attacks.
  • Display code: Show HTML/JS code on a page without it being interpreted.
  • Email/JSON: Safely represent special characters in data.
  • Accessibility: Use entities for characters not on your keyboard.
