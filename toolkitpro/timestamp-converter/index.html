What is a Unix Timestamp?

A Unix timestamp is the number of seconds (or milliseconds) that have elapsed since January 1, 1970 at 00:00:00 UTC (the Unix epoch). It is a universal, timezone-independent way to represent time — used by databases, APIs, and programming languages.

Common Timestamp Examples

  • 0 → January 1, 1970 00:00:00 UTC (the epoch)
  • 1000000000 → September 9, 2001 01:46:40 UTC
  • 1700000000 → November 14, 2023 22:13:20 UTC
  • 1800000000000 (ms) → January 15, 2027 08:40:00 UTC

Why Use Timestamps?

  • Universal: Same value everywhere, no timezone confusion
  • Sortable: Larger = later, so sorting is trivial
  • Compact: 10-13 digits vs a full date string
  • Standard: Used by JavaScript, Python, MySQL, APIs
