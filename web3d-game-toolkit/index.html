⚙️ 1. 3D 引擎（自写 WebGL，无 Three.js）

原生 WebGL 自写引擎：矩阵数学(M4)、透视相机(Camera)、几何生成器(GEO: 立方体/球/圆柱/圆锥)、WebGL 渲染器(Renderer3D)、复合模型(Model)、碰撞(circleCollides)。

拖拽旋转查看 Modeler 生成的模型

引擎 API 一览

  • M4 — 矩阵：identity/multiply/perspective/translation/rotationX/rotationY/scale
  • Camera — 第一人称相机：viewMatrix/projMatrix/forward/right
  • GEO — 几何生成器：box/sphere/cylinder/cone/translate/scale/merge
  • Renderer3D — 渲染器：begin/drawGLMesh/drawModel/drawBox/drawGround
  • Model — 复合模型：parts(几何+颜色+偏移)
  • circleCollides — 圆形 vs AABB 碰撞（XZ）

🔄 4. 开发流程

1

需求与设计

明确玩法/目标/平台(PC+手机)，设计核心循环、美术风格、数值框架。

2

搭建引擎

自写 WebGL 渲染管线：矩阵/相机/网格/光照/碰撞，或选型轻量引擎。

3

程序化建模

用 Modeler 几何生成器(立方体/球/圆柱/圆锥)组合场景/角色/道具/NPC 模型。

4

游戏逻辑

输入(键鼠/触摸)、实体系统、AI、射击/命中、UI/HUD、状态机。

5

测评优化

用 GameQA 测性能/可玩性/难度/稳定性，针对问题优化(合批/低多边形/平衡)。

6

发布

打包(静态/压缩)、部署(GitHub Pages/CDN)、移动端适配、埋点观测。

🛠️ 5. 技能清单

WebGL 着色器/缓冲矩阵数学 变换/投影 3D 几何 网格/碰撞程序化建模 几何组合 游戏循环 rAF/物理输入系统 键鼠/触摸 游戏 AI 状态/寻路性能优化 合批/剔除 移动端适配 响应式/触控测评 性能/可玩性 发布部署 静态托管数据分析 埋点/留存
