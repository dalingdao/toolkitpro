需求优先级矩阵

输入需求的价值/成本/风险/依赖 → 四维量化 → 优先级得分排序 + 矩阵图。产品经理需求排期、Scrum 冲刺规划必备。支持 Agent JSON 接口。

实用场景：产品经理每季度要排需求优先级，光看"价值高"不够——还要看成本、风险、依赖。手动权衡易拍脑袋，本工具把价值/成本/风险/依赖四维量化，自动算出优先级得分并排序，生成 P0/P1/P2/P3 分级 + 矩阵图，直接进排期文档。

输入需求（每行一个：名称,价值,成本,风险,依赖）

示例

实用场景与实例

场景：产品经理冲刺规划；Scrum 团队排 backlog。痛点：只凭"价值"排序会忽略成本/风险/依赖，导致高风险高成本需求排太前。用法：输入需求四维评分 → 得到优先级得分+排序+P0-P3分级+矩阵图。
实例：输入"用户登录,9,2,2,1"和"支付系统,8,6,5,3"——登录价值9/成本2/风险2/依赖1 → 得分高（低成本高价值）排P0；支付系统成本6/风险5/依赖3 → 排后。符合"先做低风险高价值"的排期逻辑。
Agent 用法：访问 ?tool=priority-matrix&input={"items":[{"name":"登录","value":9,"cost":2,"risk":2,"dep":1}]}&format=json 返回 JSON（排序+分级+矩阵），Agent 可直接读入排期。
