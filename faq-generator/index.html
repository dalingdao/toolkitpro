FAQ 智能整理器

输入零散问答 → 自动归类分组 + 合并重复问题 + 生成可搜索 FAQ 文档。客服知识库整理、帮助中心搭建必备。支持 Agent JSON 接口。

实用场景：客服整理知识库，收到几百条零散问答——同一问题被问几十次、问题无分类、答案不统一。本工具自动归类（按关键词）、合并重复问题、输出可搜索分组 FAQ，直接进帮助中心。

输入问答（每行：问题|答案）

实用场景与实例

场景：客服知识库整理；产品帮助中心搭建。痛点：问答零散、重复多、无分类，搜索找不到。用法：粘贴问答 → 自动归类+合并重复 → 输出分组 FAQ + 重复统计。
实例：输入多条问答（含重复"怎么退款"），点整理：自动按"退款/支付/配送/账号"归类，合并重复问题（标记重复次数），生成可搜索 FAQ 文档。
Agent 用法：访问 ?tool=faq-generator&input={"qa":[{"q":"怎么退款？","a":"7天无理由"}]}&format=json 返回 JSON（分组+合并+重复统计），Agent 可直接读入知识库。
