测试用例生成器

输入字段定义/业务规则 → 自动生成等价类+边界值+异常场景测试用例，标注优先级与覆盖类型。QA 测试用例编写必备。支持 Agent JSON 接口。

实用场景：QA 给"注册表单"写测试用例——要覆盖有效等价类、边界值（18/60 岁）、异常输入（负数/超长/空）。手动写要半小时，本工具按字段定义自动生成全场景用例 + 优先级标注，直接进测试平台。

实用场景与实例

场景：QA 编写测试用例；开发自测；测试平台导入用例。痛点：等价类/边界值/异常场景漏测，手动写慢。用法：输入字段定义 → 生成等价类+边界值+异常用例，标注优先级与覆盖类型。
实例：输入 {"name":"注册","fields":[{"name":"age","type":"number","min":18,"max":60,"required":true}]}：生成 age=18（边界）、60（边界）、19（有效）、17（无效）、61（无效）、空（必填）、负数（异常）等用例，标注高/中优先级。
Agent 用法：访问 ?tool=test-case-gen&input={"name":"注册","fields":[{"name":"age","type":"number","min":18,"max":60}]}&format=json 返回 JSON（用例数组），Agent 可直接读入测试框架。
