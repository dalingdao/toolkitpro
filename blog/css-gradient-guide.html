1. What is a CSS Gradient?

CSS gradients let you create smooth transitions between colors, replacing image backgrounds with pure CSS. They're fast, responsive, and scalable.

Gradients are used for:

  • Backgrounds - modern, vibrant page backgrounds
  • Buttons - eye-catching call-to-action elements
  • Text effects - gradient text with background-clip
  • Cards - visual depth and branding
  • Charts - data visualization

2. Linear Gradients

Linear gradients transition along a straight line.

Radial gradients transition from a center point outward.

4. Conic Gradients

Conic gradients rotate around a center point (like a color wheel).
