📐 CSS Flexbox Guide

A complete tutorial for CSS Flexbox — the modern one-dimensional layout system. Learn how to build responsive layouts with simple, readable code.

Quick answer: Use display:flex on the parent (container) to enable flexbox, then control alignment with justify-content (horizontal) and align-items (vertical).

What is Flexbox?

Flexbox (Flexible Box Layout) is a CSS layout module designed for one-dimensional layouts — aligning items in a row or column. It solves the classic problems of vertical centering and equal-height columns that were difficult with floats or inline-block.

Flex Container Properties

Apply these to the parent element with display:flex:

PropertyValuesDescription
flex-directionrow, column, row-reverse, column-reverseMain axis direction
justify-contentflex-start, center, flex-end, space-between, space-around, space-evenlyAlign items along main axis
align-itemsstretch, flex-start, center, flex-end, baselineAlign items along cross axis
flex-wrapnowrap, wrap, wrap-reverseWrap items to multiple lines
gaplengthSpacing between items (row-gap + column-gap)

Flex Item Properties

Apply these to the children inside the flex container:

PropertyValuesDescription
flex-grownumber (default 0)How much item grows relative to siblings
flex-shrinknumber (default 1)How much item shrinks when space is tight
flex-basislength, autoInitial main-size before growing/shrinking
align-selfauto, stretch, center, flex-start, flex-endOverride container's align-items for this item
orderintegerVisual order (lower comes first)

Flexbox vs CSS Grid

Use Flexbox for one-dimensional layouts (a row or a column of items). Use CSS Grid for two-dimensional layouts (rows and columns together). They work great together — Grid for the page skeleton, Flexbox for component-level alignment.

Common Flexbox Patterns

  • Navbar: display:flex; justify-content:space-between
  • Card grid: display:flex; flex-wrap:wrap; gap:20px
  • Sticky footer: min-height:100vh; flex-direction:column with margin-top:auto on footer
  • Input + button: display:flex; gap:8px with button fixed width

Browser Support

Flexbox is supported in all modern browsers (Chrome 29+, Firefox 28+, Safari 9+, Edge 12+, and IE 11 with prefixes). Use display:-webkit-flex for older Safari.
