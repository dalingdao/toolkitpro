1. What is CSS Grid?

CSS Grid is a two-dimensional layout system that makes it easy to design complex web layouts. Unlike Flexbox (one dimension), Grid handles both rows and columns simultaneously.

Grid is ideal for:

  • Page layouts - headers, sidebars, footers
  • Card grids - galleries, dashboards, pricing tables
  • Responsive designs - automatic reflow at any width
  • Form layouts - aligned inputs and labels

2. Grid Template Columns

grid-template-columns defines the column tracks. Use fr units for flexible sizing.

.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

repeat(3, 1fr) creates 3 equal columns. You can mix fixed and flexible:

grid-template-columns: 200px 1fr 300px; /* sidebar - content - sidebar */

3. Grid Template Areas

grid-template-areas lets you name and arrange regions:

.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar content"
    "footer footer";
  grid-template-columns: 200px 1fr;
  gap: 12px;
}
.header { grid-area: header; }

This creates a classic layout with named areas, much easier to read than coordinate-based positioning.

4. Auto-Fit & Responsive

auto-fit with minmax() creates fully responsive grids without media queries:

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}

Cards automatically wrap to the next row when the container narrows, perfect for dashboards and galleries.

5. Gap Spacing

gap controls spacing between tracks (both rows and columns):

.grid { display: grid; gap: 20px; }      /* both */
.grid { display: grid; row-gap: 10px; column-gap: 20px; }  /* separate */
