1. 什么是 JSON 格式化？

JSON 格式化（JSON Formatting）是指将压缩的 JSON 文本转换为可读的、带缩进和美化的格式。JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，广泛用于 API 响应、配置文件、数据存储等场景。

格式化后的 JSON 具有清晰的层级结构，方便开发者阅读、调试和修改数据。例如：

// 压缩格式（不易阅读）
{"name":"John","age":30,"address":{"city":"Shanghai","zip":"200000"},"tags":["dev","tools"]}

// 格式化后（清晰可读）
{
  "name": "John",
  "age": 30,
  "address": {
    "city": "Shanghai",
    "zip": "200000"
  },
  "tags": [
    "dev",
    "tools"
  ]
}

2. 为什么需要格式化 JSON？

  • 调试 API 响应：浏览器或终端中看到的压缩 JSON 难以阅读，格式化后能快速定位数据。
  • 编辑配置文件：很多现代项目（如 package.json、tsconfig.json）使用 JSON，格式化后更易编辑。
  • 学习 JSON 语法：格式化展示清晰的嵌套结构，是学习 JSON 的最佳方式。
  • 分享代码：格式化后的 JSON 更适合在团队中分享和审查。
  • 减少错误：压缩 JSON 缺少空格，格式化能发现结构错误。

4. JSON 语法完整参考

类型示例说明
对象{"key": "value"}键值对集合，用花括号包裹
数组[1, 2, 3]有序列表，用方括号包裹
字符串"hello"双引号包裹的文本
数字42 或 3.14整数或浮点数
布尔值true / false逻辑真/假
nullnull空值

JSON 规则：

  • 键名必须用双引号包裹（单引号不允许）
  • 字符串必须用双引号，不能用单引号
  • 不能有尾随逗号（如 {"a":1,} 无效）
  • 不支持注释（// 或 /* */）
  • 顶层可以是对象、数组、字符串、数字、布尔值或 null

5. 校验 JSON 的常见错误

错误示例修复
单引号{'name': 'John'}改为 {"name": "John"}
尾随逗号{"a":1,}删除逗号 → {"a":1}
缺少引号{name: "John"}键加引号 → {"name": "John"}
注释残留{/* 注释 */}删除注释
未闭合括号{"a":1补上 }
