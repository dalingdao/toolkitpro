1. What is CSS Box Shadow?

CSS box-shadow is a property that adds shadow effects to an element's box. It's one of the most powerful CSS effects for creating depth, elevation, and visual hierarchy in modern web design.

Shadows are essential for:

  • Material Design - elevation and depth cues
  • Card layouts - separating content layers
  • Buttons - interactive hover states
  • Modals - floating above page content
  • Visual emphasis - drawing attention to elements

2. Box-Shadow Syntax

box-shadow: offset-x offset-y blur-radius spread-radius color inset;

Example:

box-shadow: 10px 10px 20px rgba(0, 0, 0, 0.3);

3. Properties Explained
