广告法极限词审查器

检测文案中的极限词/绝对化用语（最、第一、国家级、顶级等），输出合规报告+替换建议。自媒体/电商/广告从业者合规必备。支持 Agent JSON 接口。

实用场景：自媒体/电商写文案怕踩"广告法极限词"被罚——不知道哪些词违规、违规在哪、怎么替换。本工具检测极限词，定位上下文+给替换建议，输出合规报告。

实用场景与实例

场景：电商详情页/直播话术/自媒体文案合规审查。痛点：踩广告法极限词（最/第一/国家级/顶级）被罚款。用法：粘贴文案 → 检测极限词 + 定位上下文 + 替换建议 + 合规报告。
实例："全国最好"→检测出"最好"（极限词）→替换建议"口碑领先"；"销量第一"→"销量领先"；"国家级"→"行业标准"。
Agent 用法：访问 ?tool=ad-compliance-checker&input={"text":"..."}&format=json 返回 JSON（违规清单+替换建议），Agent 可直接接入文案审核流。
