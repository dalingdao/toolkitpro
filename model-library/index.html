🏗️ 模型库（14 款超真模型）

🖱️ 拖拽旋转查看 · 点击模型按钮切换 · 每个模型由 5~18 个细节部件组成

📖 建模技能（创建/修改模型流程）

1

拆解真实结构

观察实物/参考图，分解为可建模的部件（如枪=枪管+机匣+弹匣+枪托+握把）。

2

部件分层

核心体(大块) → 细节(小件/铆钉/开孔) → 高光(镜片/灯/金属)。每层 2~8 部件。

3

比例与透视

按真实比例定尺寸，用 GEO.translate/scale/rotation 校正位置与朝向。

4

材质配色

主色(主体) / 辅色(配件) / 高光(金属/玻璃 alpha) / 暗色(阴影面)。

5

组合修改

part = {geo,color,x,y,z,yaw}；修改任意部件即改模型（增删部件/改色/位移）。

6

校验视角

多角度旋转预览（本页 3D 预览），确认无穿模/比例失调，微调后入库。

⚙️ 建模 API（Modeler_pro）

每个生成器返回 Model（parts 数组），可在游戏中 renderer.drawModel(model,x,y,z,scale,yaw) 绘制。修改模型：model.parts.push({geo,color,...}) 或改 color/位置。
// 建模技能核心
const m = Modeler_pro.rifle();          // 细致突击步枪(16部件)
const s = Modeler_pro.soldier(color);   // 逼真士兵(20部件)
const v = Modeler_pro.vehicle(color);   // 装甲车(13部件)
const b = Modeler_pro.building(3,5,3);  // 楼房(窗户网格)
// 修改模型：加装瞄准镜
m.parts.push({geo:GEO.cylinder(0.05,0.15,8), color:[0.1,0.1,0.12,1], y:0.2, z:0.3});
renderer.drawModel(m, x,y,z, 1.0, yaw);
