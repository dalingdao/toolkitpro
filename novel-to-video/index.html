小说转短视频生成器

把小说/文章自动切成适合短视频的分段，生成标题+字幕+分镜画面提示+背景音乐建议。自媒体短视频创作者必备。支持 Agent JSON 接口。

实用场景：自媒体人要把小说做成短视频涨粉变现——小说太长，不知道怎么切；每段要 60 秒内；标题要抓人；画面要有分镜提示。本工具自动把长文切成短视频分段（每段≤60秒），附标题+字幕+分镜+配乐建议，直接进剪辑。

实用场景与实例

场景：小说作者/自媒体做短视频变现；推文转视频。痛点：长文不好切、每段超60秒、标题弱、无分镜。用法：粘贴正文 → 自动切分段（每段≤60秒）+ 标题 + 字幕 + 分镜提示 + 配乐建议。
实例：粘贴小说段落，生成：分段1"她独自在森林中..."（标题：月影狼女·第1话，配乐：低沉悬疑）、分段2...每段字幕+分镜画面提示（森林夜景/月光/狼影）。
Agent 用法：访问 ?tool=novel-to-video&input={"title":"月影狼女","text":"..."}&format=json 返回 JSON（分段数组+标题+配乐），Agent 可直接读入剪辑流程。
